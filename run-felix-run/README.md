# RUN FELIX, RUN

A pastel psychedelic endless runner for Android.

## Current base game
- Original Felix run animation and jump pose
- Tap-anywhere jumping with variable jump height, coyote time, and jump buffering
- Endless procedural obstacle spawning
- Increasing run speed and distance score
- Collision/game-over/restart loop
- Layered scrolling pastel psychedelic world
- Touch, keyboard, and gamepad-A input
- Arm64 Android export

All graphical assets in `assets/` were created specifically for this project and are bundled with the game.
